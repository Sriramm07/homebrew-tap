# Sriramm07/homebrew-tap

Homebrew formulae for [taciTTY](https://github.com/Sriramm07/tacitty):
type `@alias` at any terminal password prompt and the real secret is sent
instead.

```sh
brew install sriramm07/tap/tacitty
tacitty init
```

Works on macOS (Apple Silicon and Intel) and Linux (x86_64 and ARM64).
Formulae are generated from each taciTTY release by
[`packaging/homebrew/update-tap.sh`](https://github.com/Sriramm07/tacitty/blob/main/packaging/homebrew/update-tap.sh).
